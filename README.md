# MAKEROW TEAMWORK — Vercel Edition

Веб-панель на React + TypeScript + Express, адаптированная для Vercel Functions и Neon PostgreSQL.

## Возможности

- Вход и регистрация только по инвайт-ключу.
- Инвайты создаются только администратором; есть срок действия, лимит использований и отзыв.
- Администратор может банить/разбанивать пользователей, выключать доступ и сбрасывать пароли.
- Проверка матчей Dota 2 через персональный STRATZ API Key каждого пользователя.
- Оценка инвентарей через LZT Market (`app_id=570`, USD), без прямых запросов к Steam.
- Проверка Steam-профиля по ссылке.
- Фильтры от $1 и от $120.
- Discord-уведомления в заданный канал.
- Пароли хешируются Argon2id; в БД сохраняются хеши сессий и инвайтов, а не открытые значения.
- Персональные STRATZ API Key шифруются AES-256-GCM и хранятся отдельно для каждого пользователя.
- LZT-запросы получают общий межинстансовый интервал через PostgreSQL, чтобы параллельные Vercel-инстансы не обходили лимит.

## Стек

- React 18 + Vite + TypeScript
- Express 5 на Vercel Node.js Functions
- Neon PostgreSQL через `@neondatabase/serverless`
- Vercel Hobby: функция проверки настроена на `maxDuration: 300` секунд

## Быстрый деплой

Полная инструкция находится в `DEPLOY_VERCEL_RU.md`.

1. Создай приватный GitHub-репозиторий.
2. Загрузи в него содержимое этой папки целиком.
3. Импортируй репозиторий на https://vercel.com/new.
4. Подключи Neon PostgreSQL через Vercel Marketplace / Storage.
5. Добавь серверные переменные окружения из `.env.example`. STRATZ API Key каждый пользователь добавляет самостоятельно в разделе «Мои API-ключи» после входа.
6. Deploy.

После первого API-запроса пустая база автоматически создаст первоначального администратора из `ADMIN_USERNAME` и `ADMIN_PASSWORD`.

## Локальный запуск

Нужен Node.js 22+ и доступная Neon PostgreSQL база.

```bash
npm install
cp .env.example .env
# Заполни DATABASE_URL, ADMIN_PASSWORD, LZT_API_TOKEN и APP_ENCRYPTION_KEY в .env
npm run dev
```

Vite откроется на `http://localhost:5173`, Express API — на `http://localhost:8080`.

## Важные ограничения

- Vercel Hobby предназначен для личных некоммерческих проектов. Не используй его для платного сервиса без проверки условий тарифа.
- Vercel Functions не являются постоянно работающим фоновым процессом. Поэтому проверка матча выполняется внутри одного HTTP-запроса и возвращает результат после завершения. При обычных 10 игроках и интервале LZT 3,25 секунды ожидается около 30–40 секунд; настройка функции допускает до 300 секунд на Hobby при Fluid Compute.
- Если LZT вернёт повторный 429 или внешний API зависнет, запрос может завершиться ошибкой/тайм-аутом.
- Neon — отдельная база. Старые локальные SQLite-аккаунты автоматически не переносятся; при первом развёртывании создаётся новый администратор из переменных окружения.
- Не добавляй `.env` в GitHub. LZT_API_TOKEN и APP_ENCRYPTION_KEY вносятся только в Vercel → Project → Settings → Environment Variables. Каждый пользователь добавляет свой STRATZ API Key в приложении → «Мои API-ключи»; ключ шифруется на сервере и хранится отдельно для его аккаунта.
- Discord Bot Token, опубликованный ранее в переписке, следует сбросить и добавить новый токен только в Vercel Environment Variables.
